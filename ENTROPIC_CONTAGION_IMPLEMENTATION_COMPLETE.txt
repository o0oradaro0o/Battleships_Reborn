=== CODE ARCHITECTURE ===

**Three Main Modifiers:**

1. **modifier_item_chaos_poison_mix_ult_bow** (Weapon Firing)
   - Handles weapon firing every 0.3 seconds
   - Finds random enemy targets in range
   - Creates tracking projectiles
   - Uses OnIntervalThink for continuous firing

2. **modifier_entropic_cloud_thinker** (Cloud AI)
   - Controls individual cloud behavior
   - Updates cloud position with drift velocity
   - Detects units in AoE radius (0.1s interval)
   - Applies/refreshes poison debuffs
   - Self-destructs after lifetime expires
   - Manages cloud particle effects

3. **modifier_entropic_poison_debuff** (Poison Damage)
   - Tracks poison stack count (1-5)
   - Deals damage every 0.5 seconds
   - Damage scales with stack count
   - Duration refreshes on re-entry (3s)
   - Shows visual poison effect
   - Displays stack count to players

=== TECHNICAL IMPLEMENTATION DETAILS ===

**Particle System:**
- Projectile: particles/darkness_chaos_ult.vpcf (custom)
- Cloud: particles/units/heroes/hero_venomancer/venomancer_plague_ward_ambient.vpcf
- Poison Debuff: particles/units/heroes/hero_venomancer/venomancer_poison_debuff.vpcf
- Impact: particles/units/heroes/hero_shadow_demon/shadow_demon_soul_catcher.vpcf
- All particles precached in Precache() function

**Cloud Spawning:**
- Uses npc_dota_thinker dummy units (invisible, invulnerable)
- Spawned with 0.05s stagger delay to prevent simultaneous spawn
- Random offset from impact point (-50 to +50 units X/Y)
- Drift direction calculated using trigonometry (random angle)
- Drift velocity applied via SetAbsOrigin() every 0.1s

**Poison Application:**
- Uses FindUnitsInRadius() every 0.1s to detect units in cloud
- Checks for existing poison modifier via FindModifierByName()
- If exists: ForceRefresh() to add stack and reset duration
- If new: AddNewModifier() with initial parameters
- Stack increment capped at max_stacks value

**Memory Management:**
- All particles stored and properly destroyed
- Timers check entity validity (IsNull())
- Cloud thinkers self-destruct after lifetime
- Poison particles cleaned up in OnDestroy()
- Dummy units killed via ForceKill(false)

=== BALANCE CONSIDERATIONS ===

**Base DPS:** 500 (150 damage × 3.33 shots/sec)
**Cloud Bonus:** Variable (~100-300 DPS when triggered)
- 15% trigger rate = ~1 trigger per 6-7 shots
- Each trigger spawns 2-4 clouds
- Each cloud deals 40-60 damage per 0.5s per stack
- Max poison DPS per target: 60 × 5 stacks × 2 ticks/sec = 600 DPS
- Clouds drift, making full poison stacking situational

**Effective DPS Range:** 500-1100 DPS
- Low end: No clouds active
- High end: Target standing in multiple overlapping clouds with max stacks

**Cloud Management:**
- Max ~12 clouds active simultaneously (3 triggers × 4 clouds, 8s lifetime)
- Clouds drift away, naturally spreading across battlefield
- Overlap chance moderate, rewards target positioning
