===========================================
MAGMA TRAIL CANNON - CRASH FIX
===========================================
Date: November 14, 2025

===========================================
PROBLEM
===========================================

The Magma Trail Cannon was crashing the game when trying to fire projectiles.

CRASH CAUSE:
The weapon was trying to load a custom particle file:
"particles/basic_projectile/magma_trail_cannon_projectile.vpcf"

However, this particle file only existed in the CONTENT folder, not the compiled GAME folder.

Particle files need to be compiled from:
- content/battleships_traders/particles/*.vpcf

To:
- game/battleships_traders/particles/*.vpcf_c

The game crashes when trying to load a particle that doesn't exist in the compiled game folder.

===========================================
SOLUTION APPLIED
===========================================

Changed the projectile particle from the custom (non-existent) file to an existing compiled particle:

BEFORE:
```lua
self.particle = "particles/basic_projectile/magma_trail_cannon_projectile.vpcf"
```

AFTER:
```lua
self.particle = "particles/basic_projectile/fire_ult_projectile.vpcf"
```

Also updated the Precache() function to match.

===========================================
WHY THIS WORKS
===========================================

The fire_ult_projectile.vpcf is:
✓ Already compiled and exists in game folder
✓ Has a fire/lava theme (perfect for magma)
✓ Uses similar hero effects (Jakiro, Batrider, Ogre Magi, Invoker, Ember Spirit)
✓ Visually appropriate for a magma weapon

The weapon now uses the same projectile as the regular fire ultimate, which fits thematically since it's a Fire/Coal mix.

===========================================
FUTURE: CUSTOM PARTICLE (OPTIONAL)
===========================================

If you want to create a truly custom projectile particle:

1. KEEP THE EXISTING .vpcf FILE:
   content/battleships_traders/particles/basic_projectile/magma_trail_cannon_projectile.vpcf

2. COMPILE IT:
   You need to compile particles using the Dota 2 Workshop Tools:
   - Open Workshop Tools
   - Open Asset Browser
   - Find your .vpcf file
   - Right-click → Compile
   - Or use the compile_particles script if available

3. VERIFY COMPILATION:
   Check that this file exists:
   game/battleships_traders/particles/basic_projectile/magma_trail_cannon_projectile.vpcf_c

4. UPDATE THE CODE:
   Change back to:
   self.particle = "particles/basic_projectile/magma_trail_cannon_projectile.vpcf"

HOWEVER: The fire_ult_projectile already looks great and fits the theme perfectly, so a custom particle is optional!

===========================================
LESSON LEARNED
===========================================

When creating new weapons with custom particles:

1. OPTION A (EASIEST):
   Use existing compiled particles from the game folder
   Check: game/battleships_traders/particles/basic_projectile/
   All files ending in .vpcf_c are available to use

2. OPTION B (ADVANCED):
   Create custom .vpcf files in content folder
   BUT: They must be compiled before the game can use them
   
3. ALWAYS TEST:
   Make sure particles exist before referencing them
   Game will crash if particle path is invalid
