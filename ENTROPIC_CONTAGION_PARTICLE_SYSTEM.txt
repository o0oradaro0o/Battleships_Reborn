=== ENTROPIC CONTAGION - CUSTOM PROJECTILE PARTICLE ===

Date: November 15, 2025
Status: ✅ COMPLETE

=== OVERVIEW ===

Created a custom projectile particle system for Entropic Contagion that combines chaos energy (purple) with toxic poison (green) for a unique infectious appearance. The projectile features:

- **Green-to-purple color transition** (infectious poison to chaotic energy)
- **Trailing toxic mist** with plasma-like trails
- **Pulsing glow effect** that shifts between green and purple
- **Chaotic sparks** that emit erratically from the projectile
- **Venomous explosion** on impact (reusing Venomancer effect)

=== FILES CREATED ===

**Main Projectile:**
1. ✅ `content/battleships_traders/particles/basic_projectile/entropic_contagion_projectile.vpcf`
   - Core projectile definition
   - Light emission: Green-tinted (150, 255, 100)
   - Radius scale: 250 units
   - Max velocity: 1200 units/sec
   - Color interpolation: Green → Purple over time

**Child Particles:**
2. ✅ `content/battleships_traders/particles/basic_projectile/entropic_contagion_trail.vpcf`
   - Toxic trail effect using beam plasma texture
   - 64 max particles, continuous emission at 80/sec
   - Green (100, 255, 150) fading to purple (150, 50, 255)
   - Trail length: 0.2-0.4 units
   - Lifetime: 0.3-0.5 seconds

3. ✅ `content/battleships_traders/particles/basic_projectile/entropic_contagion_glow.vpcf`
   - Glowing aura around projectile
   - 32 max particles, continuous emission at 45/sec
   - Radius: 25-40 units
   - Color oscillation between green-cyan and purple
   - Additive blending for bright glow effect

4. ✅ `content/battleships_traders/particles/basic_projectile/entropic_contagion_chaos_sparks.vpcf`
   - Chaotic purple sparks with erratic movement
   - 48 max particles, continuous emission at 90/sec
   - Purple (150-200, 50-100, 255) with green fade
   - Vector noise for unpredictable movement
   - Small radius: 2-5 units (spark-like)

=== VISUAL CHARACTERISTICS ===

**Color Palette:**
- Primary: Toxic Green (100, 255, 150)
- Secondary: Chaos Purple (150, 50, 255)
- Accent: Cyan-Green (150, 255, 100)
- Highlight: Bright Purple (200, 100, 255)

**Effects Breakdown:**

1. **Core Glow** (entropic_contagion_projectile.vpcf)
   - Deferred light renderer for volumetric appearance
   - Bright green-white center with purple edges
   - Scales up slightly as it travels (0.3 → 1.0 scale)
   - Random color variation between green and cyan

2. **Toxic Trail** (entropic_contagion_trail.vpcf)
   - Rendered as beam trails (plasma texture)
   - Leaves glowing green-purple wake
   - Fades from green to deep purple over lifetime
   - Trail persistence: 0.3-0.5 seconds
   - Rotation effect for dynamic appearance

3. **Aura Glow** (entropic_contagion_glow.vpcf)
   - Large soft glow particles
   - Additive blending for brightness boost
   - Pulsates between green and purple
   - Creates diffuse halo around projectile
   - Interpolates radius (0.5 → 2.0 scale)

4. **Chaos Sparks** (entropic_contagion_chaos_sparks.vpcf)
   - Small bright flares (aircraft_white texture)
   - Erratic movement using vector noise
   - Purple-dominant with green fade
   - Gravity-affected for realistic physics
   - Rapid fade out (0.2-0.5 sec lifetime)

**Impact Effect:**
- Reuses Venomancer venomous gale explosion
- Green burst with toxic spray
- Triggers on EndCap (projectile hit/end)

=== TECHNICAL DETAILS ===

**Particle System Architecture:**

```
entropic_contagion_projectile.vpcf (PARENT)
├── entropic_contagion_trail.vpcf (CHILD - continuous trail)
├── entropic_contagion_glow.vpcf (CHILD - aura effect)
├── entropic_contagion_chaos_sparks.vpcf (CHILD - sparks)
└── venomancer_venomousgale_explosion.vpcf (ENDCAP - impact)
```

**Performance Optimization:**
- Total max particles: 160 (1 + 64 + 32 + 48 + explosion)
- Emission controlled to balance visual impact vs performance
- Particles use additive blending (GPU-friendly)
- Trail particles auto-cleanup after lifetime
- No expensive physics calculations (basic movement only)

**Control Points:**
- CP 0: Projectile origin (source)
- CP 1: Target position
- CP 2: Velocity override (1200 max)
- CP 3: Orientation tracking
- CP 4: Attraction point (for homing)

=== COMPILATION INSTRUCTIONS ===

**To Compile Particles in Workshop Tools:**

1. Open Dota 2 Workshop Tools
2. Open Particle Editor (Tools → Particle Editor)
3. File → Open each .vpcf file:
   - entropic_contagion_projectile.vpcf
   - entropic_contagion_trail.vpcf
   - entropic_contagion_glow.vpcf
   - entropic_contagion_chaos_sparks.vpcf
4. For each file:
   - Preview effect (play button)
   - Adjust if needed
   - File → Save
   - File → Compile
5. Reload custom game to see changes

**Troubleshooting:**

- **Particles don't show:** Check precache in Lua, verify paths
- **Purple/green missing:** Color controls may need adjustment
- **Performance issues:** Reduce emission rates (80 → 60, 45 → 30, 90 → 60)
- **Trail too thick:** Reduce flRadiusScale in trail.vpcf
- **Glow too bright:** Lower flOverbrightFactor in renderers

=== ALTERNATIVE CUSTOMIZATION OPTIONS ===

**If you want to adjust the appearance:**

**Make it MORE TOXIC (more green):**
- In projectile.vpcf: Change ColorScale to [ 100, 255, 100 ]
- In trail.vpcf: Change ColorMin to [ 80, 255, 120 ]
- In glow.vpcf: Remove purple ColorInterpolate

**Make it MORE CHAOTIC (more purple):**
- In projectile.vpcf: Change ColorScale to [ 200, 100, 255 ]
- In chaos_sparks.vpcf: Increase emission to 120
- In trail.vpcf: Change ColorFade start time to 0.1

**Make it BIGGER:**
- In projectile.vpcf: Increase flRadiusScale to 300
- In glow.vpcf: Increase flRadiusMax to 60
- In trail.vpcf: Increase flRadiusMax to 20

**Make it SMALLER:**
- In projectile.vpcf: Decrease flRadiusScale to 180
- In glow.vpcf: Decrease flRadiusMax to 25
- In trail.vpcf: Decrease flRadiusMax to 10
