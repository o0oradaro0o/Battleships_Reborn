===========================================
ABYSSAL RIFT CANNON - QUICK TEST GUIDE
===========================================

WHAT TO LOOK FOR WHEN TESTING
===========================================

1. WEAPON FIRING
   ✓ Fires every 0.3 seconds (fast machine gun feel)
   ✓ Dark purple/black projectile
   ✓ Sound: "Hero_Enigma.MidnightPulse" on fire
   ✓ Deals 150 damage on hit

2. PORTAL SPAWNING
   ✓ Should spawn portal ~8% of hits (roughly every 12 shots)
   ✓ Visual: Dark swirling portal at impact point
   ✓ Sound: "Hero_Enigma.Black_Hole.Cast"
   ✓ Lasts ~2 seconds

3. SPIRIT SPAWNING
   ✓ 1-5 spirits spawn from each portal
   ✓ Staggered spawn delays (0.2-0.4s between spirits)
   ✓ Each spirit has colored tint based on type
   ✓ Small shadow demon models (scaled 0.4-0.6)
   ✓ Dark trail effect following spirits

4. SPIRIT BEHAVIOR
   ✓ Spirits fly toward nearest valid target
   ✓ Can select and attack spirits (they have HP bars)
   ✓ Spirits explode on impact with visual effect
   ✓ Spirits despawn after 8 seconds if no target

   Red Spirits (40%):

   ✓ Red explosion effect

===========================================
COMMON ISSUES & FIXES
===========================================

ISSUE: Spirits don't move
FIX: Check that "npc_abyssal_spirit" unit has MovementCapabilities "DOTA_UNIT_CAP_MOVE_FLY"

ISSUE: Spirits die immediately
FIX: Make sure spirit HP is being set correctly (150-250)

ISSUE: Portals never spawn
FIX: Verify portal_chance is set to 8 in npc_items_custom.txt

ISSUE: Game crashes on spirit spawn
FIX: Verify shadow_demon model is precached properly

ISSUE: Particles don't show
FIX: All particles should be precached in Precache() function

ISSUE: Spirits target wrong team
FIX: Check target_team parameter is correct for each spirit type

ISSUE: Invisibility doesn't break on attack
FIX: Verify OnAttack and OnAbilityExecuted events in invis buff modifier

ISSUE: Too many spirits cause lag
FIX: Consider adding global spirit count limiter (max 15 total)

PERFORMANCE BENCHMARKS
===========================================

ACCEPTABLE PERFORMANCE:
- 10+ spirits active simultaneously: No lag
- 5 portals spawning rapidly: Smooth
- Fast fire rate (3.33/sec): No stutter
- Multiple buff effects active: No performance drop

RED FLAGS:
- Frame drops with 5+ spirits
- Lag when portal spawns
- Crash when many spirits spawn
- Memory leak (spirits not despawning)
