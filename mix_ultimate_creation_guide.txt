===========================================
GUIDE: CREATING UNIQUE MIX WEAPON ULTIMATES
===========================================
Template for Transforming Dual-Weapon Mix Ultimates into Unique Weapons

Based on successful implementations:
- Supernova Cannon (Plasma/Fire) - Physics knockback
- Magma Trail Cannon (Fire/Coal) - Area denial trails

===========================================
STEP 1: DESIGN THE UNIQUE MECHANIC
===========================================

DESIGN PRINCIPLES:
✓ Must be wholly original (not just combining parent ultimates)
✓ Should match ~490 DPS power level
✓ Must have clear counterplay
✓ Should be fun and visually impactful
✓ Themed around the two parent weapons

EXAMPLE MECHANICS TO CONSIDER:
- Physics effects (knockback, pull, launch)
- Area denial (ground effects, zones)
- Debuffs (slow, armor reduction, damage amplification)
- Chaining/bouncing effects
- Transformation/terrain effects
- Summoning/pet mechanics
- Multi-stage attacks

QUESTIONS TO ASK:
1. What is the core fantasy? (e.g., "leaving trails of lava")
2. How does it combine themes? (e.g., fire burn + coal lingering)
3. What is the counterplay? (e.g., move out of trails)
4. Is it visually clear? (e.g., visible danger zones)
5. Is it fun to use? (e.g., creating tactical zones)

===========================================
STEP 2: CALCULATE BALANCED STATS
===========================================

TARGET DPS: ~490 (baseline for all mix ultimates)

FORMULA:
DPS = (Damage × Projectiles) / Fire_Rate

STANDARD ULTIMATE STATS:
- Base Damage: 860 per projectile
- Projectiles: 2 per volley
- Fire Rate: 3.5 seconds
- DPS: (860 × 2) / 3.5 = 491
- Range: 650
- Speed: 1450
- Cost: 13,500 gold

ADDITIONAL EFFECTS:
- Should add situational power, not guaranteed DPS
- Example: Trail damage only if enemies stay in trail
- Example: Knockback provides utility but not direct DPS
- Keep total potential DPS reasonable (600-650 max)

===========================================
STEP 3: PLAN THE CODE STRUCTURE
===========================================

RECOMMENDED STRUCTURE:

1. MAIN ABILITY CLASS:
   - Precache() function for all particles
   - GetIntrinsicModifierName()
   - OnProjectileHit() for unique mechanic

2. MAIN WEAPON MODIFIER:
   - OnCreated(): Set up weapon stats
   - OnIntervalThink(): Fire projectiles
   - OnDestroy(): Cleanup

3. UNIQUE MECHANIC MODIFIERS:
   - Debuff modifier on hit targets
   - Thinker/aura modifiers for area effects
   - Additional debuffs on affected units

TYPICAL FILE SIZE:
- 200-400 lines of Lua code
- 4-8 total modifiers
- 5-10 particle effects

===========================================
STEP 4: IMPLEMENT THE LUA CODE
===========================================

TEMPLATE STRUCTURE:

```lua
-- [WEAPON NAME]: [Parent1]/[Parent2] Mix Ultimate Weapon
-- [Brief description of unique mechanic]

item_[name]_bow = class({})
LinkLuaModifier("modifier_item_[name]_bow", "items/item_[name].lua", LUA_MODIFIER_MOTION_NONE)
LinkLuaModifier("modifier_[unique_mechanic]", "items/item_[name].lua", LUA_MODIFIER_MOTION_NONE)
-- Link additional modifiers as needed

function item_[name]_bow:Precache(context)
  -- Precache ALL particles here to prevent lag
  PrecacheResource("particle", "path/to/particle1.vpcf", context)
  PrecacheResource("particle", "path/to/particle2.vpcf", context)
end

function item_[name]_bow:GetIntrinsicModifierName()
  return "modifier_item_[name]_bow"
end

function item_[name]_bow:OnProjectileHit(target, location)
  if not IsServer() then return end
  if target == nil then return end
  
  local caster = self:GetCaster()
  
  -- Deal primary damage
  ApplyDamage({
    victim = target,
    attacker = caster,
    damage = self:GetSpecialValueFor("dmg"),
    damage_type = DAMAGE_TYPE_PHYSICAL,
    ability = self
  })
  
  -- Create impact effects
  -- Apply unique mechanic
end

----------------------------------------------------------------------
-- Main Weapon Modifier
----------------------------------------------------------------------

modifier_item_[name]_bow = class({})

function modifier_item_[name]_bow:OnCreated(kv)
  if IsServer() then
    self.ability = self:GetAbility()
    self.parent = self:GetParent()
    self.caster = self.ability:GetCaster()
    
    -- Set weapon stats
    self.fire_rate = self.ability:GetSpecialValueFor("fire_rate")
    self.damage = self.ability:GetSpecialValueFor("dmg")
    self.range = self.ability:GetSpecialValueFor("range")
    self.speed = self.ability:GetSpecialValueFor("speed")
    self.num_attacks = 2
    
    -- Set particle and sound
    self.particle = "particles/path/to/projectile.vpcf"
    self.fire_sound = "Hero_Name.Sound"
    
    self:StartIntervalThink(self.fire_rate)
  end
end

function modifier_item_[name]_bow:OnIntervalThink()
  if IsServer() then
    local enemies = FindUnitsInRadius(
      self.parent:GetTeam(),
      self.parent:GetAbsOrigin(),
      nil,
      self.range,
      DOTA_UNIT_TARGET_TEAM_ENEMY,
      DOTA_UNIT_TARGET_HERO + DOTA_UNIT_TARGET_BASIC + DOTA_UNIT_TARGET_BUILDING,
      DOTA_UNIT_TARGET_FLAG_NO_INVIS + DOTA_UNIT_TARGET_FLAG_FOW_VISIBLE + DOTA_UNIT_TARGET_FLAG_NOT_ATTACK_IMMUNE,
      FIND_ANY_ORDER,
      false
    )
    
    for i = 1, self.num_attacks do
      if TableCount(enemies) > 0 then
        local target = GetRandomTableElement(enemies)
        
        local projectile = {
          Target = target,
          Source = self.parent,
          Ability = self.ability,
          EffectName = self.particle,
          iMoveSpeed = self.speed,
          bDodgeable = true,
          bVisibleToEnemies = true,
          bReplaceExisting = false,
          bProvidesVision = false,
          iSourceAttachment = DOTA_PROJECTILE_ATTACHMENT_HITLOCATION
        }
        ProjectileManager:CreateTrackingProjectile(projectile)
        EmitSoundOn(self.fire_sound, self.caster)
      end
    end
  end
end
```

===========================================
STEP 8: TESTING AND ITERATION
===========================================

TESTING CHECKLIST:
☐ Weapon fires correct number of projectiles
☐ Damage is correct (~490 DPS)
☐ Unique mechanic works as intended
☐ Visual effects appear correctly
☐ No lag on first hit (particles precached)
☐ Sound effects play appropriately
☐ Tooltip is accurate and clear
☐ Weapon is fun to use
☐ Balance feels appropriate
☐ Performance is good

COMMON ISSUES:
- First hit lag: Missing Precache() calls
- No particles: Wrong file paths
- No damage: Check damage type and flags
- Mechanic not working: Verify modifier links
- Performance issues: Too many particles/thinkers

ITERATION:
1. Test in-game
2. Gather feedback
3. Adjust numbers (damage, duration, radius)
4. Polish effects
5. Retest

===========================================
DESIGN ANTI-PATTERNS (AVOID THESE)
===========================================

❌ DON'T just combine parent ultimates
   Example: Fire ultimate + Coal ultimate = boring

❌ DON'T make it too complex
   Example: 10 different effects that confuse players

❌ DON'T ignore counterplay
   Example: Unavoidable massive damage with no downside

❌ DON'T forget visual feedback
   Example: Invisible danger zones

❌ DON'T break DPS balance
   Example: 800+ guaranteed DPS

❌ DON'T forget to precache particles
   Example: Lag spike on first hit

❌ DON'T make it unfun to play against
   Example: Permanent disable with no counterplay
