=== ENTROPIC CONTAGION - CHAOS/POISON MIX ULTIMATE WEAPON ===

Transform the chaos/poison mix ultimate weapon from a dual-weapon system into a unique single weapon called "Entropic Contagion" that fires infectious projectiles. When projectiles hit, they spawn toxic clouds that drift away from the impact point, poisoning any units that enter them.

=== CRITICAL LESSONS FROM ABYSSAL RIFT CANNON IMPLEMENTATION ===

**Particle Management:**
- ALWAYS verify particles exist using PowerShell in Dota 2 directory:
  ```powershell
  Get-ChildItem -Path "." -Filter "*.vpcf*" -Recurse | Where-Object { $_.Name -like "*venomancer*poison*" }
  ```
- Use FULL particle paths: "particles/units/heroes/hero_name/particle_name.vpcf"
- Custom particles go in content/battleships_traders/particles/ folder
- Precache ALL particles in Precache() function to prevent lag
- Store particle indices and destroy them properly to prevent memory leaks

**Timer Management:**
- Use Timers:CreateTimer() for delayed effects (cloud spawning with stagger)
- Pass entity references carefully - check if entity IsNull() before using
- Example: Timers:CreateTimer(delay, function() if caster and not caster:IsNull() then ... end end)

**Modifier System Best Practices:**
- Use separate modifiers for different mechanics:
  * Main weapon firing modifier (OnIntervalThink for shooting)
  * Cloud thinker modifier (handles cloud drift and poison application)
  * Poison debuff modifier (tracks stacks and applies damage)
- Store critical data in modifier properties (self.cloud_position, self.drift_direction, etc.)
- Use DeclareFunctions() to hook into game events
- Clean up in OnDestroy() - destroy particles, kill dummy units, etc.

**Cloud Implementation Pattern:**
```lua
-- Create invisible dummy unit for each cloud at impact location
local cloud = CreateUnitByName("npc_dota_thinker", spawn_position, false, caster, caster, caster:GetTeam())
cloud:AddNewModifier(caster, self, "modifier_entropic_cloud_thinker", {
  lifetime = 8.0,
  drift_x = random_direction.x,
  drift_y = random_direction.y,
  drift_speed = RandomInt(100, 200),
  poison_damage = RandomInt(40, 60)
})

-- In modifier_entropic_cloud_thinker:OnIntervalThink() (0.03s interval):
-- 1. Update cloud position using SetAbsOrigin() with drift velocity
-- 2. Find units in radius using FindUnitsInRadius()
-- 3. Apply poison modifier to units in AoE
-- 4. Destroy cloud after lifetime expires
```

**Unit Collision and Pathing:**
- Clouds (dummy units) should have no collision: CheckState() returns MODIFIER_STATE_NO_UNIT_COLLISION
- Use MODIFIER_STATE_NOT_ON_MINIMAP, MODIFIER_STATE_NO_HEALTH_BAR for invisible thinkers
- Use MODIFIER_STATE_INVULNERABLE so clouds can't be attacked

**Stacking Poison Mechanic:**
```lua
-- In poison debuff modifier:
function modifier_entropic_poison:OnCreated()
  if IsServer() then
    self.stack_count = 1
    self.max_stacks = 5
    self:SetStackCount(1)
    self.damage_per_tick = params.damage or 50
    self:StartIntervalThink(0.5) -- Tick every 0.5 seconds
  end
end

function modifier_entropic_poison:OnRefresh()
  if IsServer() then
    -- Increment stacks up to max
    local stacks = math.min(self:GetStackCount() + 1, self.max_stacks)
    self:SetStackCount(stacks)
    self:SetDuration(3.0, true) -- Refresh duration
  end
end

function modifier_entropic_poison:OnIntervalThink()
  if IsServer() then
    local damage = self.damage_per_tick * self:GetStackCount()
    ApplyDamage({
      victim = self:GetParent(),
      attacker = self:GetCaster(),
      damage = damage,
      damage_type = DAMAGE_TYPE_MAGICAL,
      ability = self:GetAbility()
    })
  end
end
```

**Debugging Approach:**
- Remove ALL debug print() statements after testing
- Use console logging during development to track:
  * Cloud spawn counts and positions
  * Drift direction calculations
  * Poison application and stack counts
  * Particle creation/destruction
- Test in-game with: -createhero tusk enemy

**Common Pitfalls to Avoid:**
1. ❌ Don't use deprecated APIs: MoveToTargetToAttack() → Use ExecuteOrderFromTable() instead
2. ❌ Don't forget to check entity validity: if entity:IsNull() or not entity:IsAlive()
3. ❌ Don't leave particles running forever: Always DestroyParticle() and ReleaseParticleIndex()
4. ❌ Don't spawn too many clouds: Limit to 2-4 per trigger to avoid performance issues
5. ❌ Don't use GetEffectName() and GetEffectAttachType() for buff modifiers - manually create particles in OnCreated() and destroy in OnDestroy()
