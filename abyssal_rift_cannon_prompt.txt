THEME:
A reality-tearing weapon that opens portals to the abyss. Ghostly spirits emerge from rifts and seek targets to kamikaze into, creating unpredictable battlefield chaos. Spirits may damage enemies, heal allies, or apply debuffs depending on their type.

WEAPON STATS (Target ~490 DPS):
- Base Impact Damage: 150 per projectile
- Fire Rate: 0.3 seconds (very fast firing - machine gun style)
- Range: 650
- Projectile Speed: 1400
- Projectiles per Volley: 1 (single shot)
- Impact DPS: 500 (150 / 0.3)
- Portal Spawn Chance: 8% per hit (lower due to fast fire rate)
- Spirit DPS: ~0 (bonus damage when portals spawn)
- Total Target DPS: ~500 + bonus from portal spawns
- Item Cost: 13,500

UNIQUE MECHANIC: PORTAL SUMMONING

When a projectile hits a target:
1. Deal direct damage to the primary target (150)
2. 8% chance to create an Abyssal Portal effect at impact point
3. If portal spawns: Summon 1-5 ghost spirits from the portal (random count)
4. Spirits seek and kamikaze into nearby units
5. Spirits are attackable and can be killed before impact
6. Different spirit types have different effects

PORTAL PARAMETERS:
- Portal Visual Duration: 2.0 seconds
- Portal Opening Effect: Expand from point, dark energy swirl
- Spirit Spawn Delay: 0.2-0.4s between spirits
- Number of Spirits: RandomInt(1, 5)
- Portal Radius (spawn area): 200

SPIRIT AI LOGIC:
```lua
-- Spirit targets nearest valid unit within acquisition range
-- Priority: Closest unit of correct team
-- If no targets found within 8 seconds, spirit despawns
-- If spirit is killed before impact, no effect triggers
-- Spirits can be attacked like regular units
```

IMPLEMENTATION APPROACH:

1. OnProjectileHit():
   - Deal primary damage to target (150)
   - Roll for portal spawn: 8% chance (RandomInt(1, 100) <= 8)
   - If portal spawns:
     * Create portal particle at impact location
     * Call SpawnSpiritsFromPortal(impact_location)
     * Play portal opening sound
   - If no portal: Just show impact effect

2. SpawnSpiritsFromPortal(location):
   - Determine number of spirits: RandomInt(1, 5)
   - For each spirit:
     * Delay spawn by 0.2-0.4s (staggered)
     * Determine spirit type (weighted random)
     * Call CreateSpirit(location, type)

3. CreateSpirit(location, type):
   - CreateUnitByName("npc_abyssal_spirit")
   - Set HP, movement speed, team, vision
   - Apply visual tint based on type
   - Store spirit type in modifier
   - Add modifier_abyssal_spirit_ai
   - Attach trail particle effect

4. modifier_abyssal_spirit_ai:
   - IsHidden: true
   - OnIntervalThink (0.1s): Seek nearest valid target
   - CheckState: MODIFIER_STATE_NO_UNIT_COLLISION
   - DeclareFunctions: MODIFIER_PROPERTY_TRANSLATE_ACTIVITY_MODIFIERS
   - OnDestroy: Despawn spirit unit

5. Spirit Impact Detection:
   - OnOrder: If order is attack/move towards target
   - Check distance to target every 0.1s
   - If distance < 100 units: Trigger impact effect
   - Apply effect based on spirit type
   - Destroy spirit unit

BALANCE CONSIDERATIONS
===========================================

DPS CALCULATION:
- Direct Hit DPS: 150 / 0.3 = 500 DPS (consistent base damage)
- Fire Rate: 3.33 shots per second (very fast)
- Portal Spawn Rate: 8% of shots (~0.27 portals per second)
- Average Spirits per Portal: (1+5)/2 = 3 spirits
- Average Spirit Damage (when portal spawns):
  * 40% chance × 250 damage = 100
  * 18% chance × 100 damage = 18
  * 12% chance × 50 damage = 6
  * Average damage per spirit = 124 damage
- Bonus DPS from Spirits: 3 spirits × 124 damage × 0.08 portal chance / 0.3s = ~99 DPS
- Total Average DPS: 500 + 99 = ~599 DPS (higher due to spirit bonus)
- Note: Fast fire rate means more frequent portal procs despite lower chance
- Note: Buff spirits provide utility value not reflected in DPS

COUNTERPLAY & BALANCE:
- Spirits can be killed (150-250 HP each)
- AOE damage destroys multiple spirits quickly
- Spirits have limited lifetime (8s)
- Random spirit count creates variance
- Some spirits help enemies (heal/buff) if they target wrong team
- Spirits are visible and telegraphed
- Spirit movement can be predicted and avoided

RANDOMNESS FACTORS:
1. Portal spawn chance (8% per shot)
2. Number of spirits (1-5)
3. Spirit types (weighted random)
4. Target selection (nearest valid unit)
5. Fast fire rate means frequent rolls for portal spawns
6. Multiple rapid shots create chaos and unpredictability

UNIQUE GAMEPLAY ELEMENTS:
- Machine-gun feel with fast fire rate (0.3s)
- Exciting portal procs despite lower % (8% × 3.33 shots/sec = ~0.27 portals/sec)
- Area denial (spirits chase enemies)

SPIRIT AI TARGETING:
```lua
function modifier_abyssal_spirit_ai:OnIntervalThink()
  local spirit = self:GetParent()
  local caster = self:GetCaster()
  local ability = self:GetAbility()
  
  -- Determine target team based on spirit type
  local target_team = DOTA_UNIT_TARGET_TEAM_ENEMY
  if spirit_type == "healing" or spirit_type == "buff" then
    target_team = DOTA_UNIT_TARGET_TEAM_FRIENDLY
  end
  
  -- Find nearest target
  local targets = FindUnitsInRadius(
    spirit:GetTeam(),
    spirit:GetAbsOrigin(),
    nil,
    800,  -- acquisition range
    target_team,
    DOTA_UNIT_TARGET_HERO + DOTA_UNIT_TARGET_BASIC,
    DOTA_UNIT_TARGET_FLAG_NO_INVIS,
    FIND_CLOSEST,
    false
  )
  
  if #targets > 0 then
    local target = targets[1]
    
    -- Check distance to target
    local distance = (target:GetAbsOrigin() - spirit:GetAbsOrigin()):Length2D()
    
    if distance < 100 then
      -- Close enough - trigger impact
      self:TriggerSpiritImpact(target)
    else
      -- Move towards target
      spirit:MoveToTargetToAttack(target)
    end
  else
    -- No targets found - wander or despawn
    if self.lifetime > 8.0 then
      spirit:ForceKill(false)
    end
  end
end
```

function modifier_abyssal_spirit_ai:TriggerSpiritImpact(target)
  local spirit = self:GetParent()
  local caster = self:GetCaster()
  local ability = self:GetAbility()
  local impact_location = spirit:GetAbsOrigin()
  
  -- Apply effect based on spirit type
  if self.spirit_type == "damage" then
    ApplyDamage({
      victim = target,
      attacker = caster,
      damage = self.damage,
      damage_type = DAMAGE_TYPE_MAGICAL,
      ability = ability
    })
    
    -- Create particle effect
    local particle = ParticleManager:CreateParticle(
      "particles/units/heroes/hero_terrorblade/terrorblade_sunder_eruption.vpcf",
      PATTACH_ABSORIGIN,
      target
    )
    ParticleManager:ReleaseParticleIndex(particle)
    
    EmitSoundOn("Hero_Terrorblade.Sunder.Cast", target)
    
  elseif self.spirit_type == "stun" then

COMMON PITFALLS & SOLUTIONS
===========================================

PITFALL: Spirits don't move or stand still
SOLUTION: Ensure MovementCapabilities is MOVE_FLY, check spirit:MoveToTargetToAttack() call

PITFALL: Spirits immediately despawn or die
SOLUTION: Verify SetHealth() is called, check for unintended damage sources

PITFALL: Spirit targeting wrong team
SOLUTION: Verify DOTA_UNIT_TARGET_TEAM_ENEMY vs FRIENDLY based on spirit type

PITFALL: Spirits impact multiple times
SOLUTION: Add flag to prevent double-trigger, use spirit:ForceKill() immediately after impact

PITFALL: Portal spawns spirits at wrong location
SOLUTION: Use impact_point from OnProjectileHit, not caster or target position

PITFALL: Spirit particles don't show
SOLUTION: Ensure all particles precached, check PATTACH type, verify particle path

PITFALL: Memory leak from spirits
SOLUTION: Always call spirit:ForceKill(false) or RemoveSelf(), clean up modifiers in OnDestroy

PITFALL: Too many spirits lag the game
SOLUTION: Add global spirit count limiter, cap max spirits per portal, reduce spirit lifetime

PITFALL: Spirit AI freezes game
SOLUTION: Use OnIntervalThink with 0.1s or longer, avoid while loops, check nil values

PITFALL: Spirits attack instead of kamikaze
SOLUTION: Set AttackCapabilities to NO_ATTACK in npc_units_custom.txt
