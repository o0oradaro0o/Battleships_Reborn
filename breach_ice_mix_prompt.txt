A. CREATE PYTHON SCRIPT: content/battleships_traders/panorama/images/items/create_breach_ice_mix.py

```python
from PIL import Image
import os

def create_hybrid_image(breach_path, ice_path, output_path):
    """
    Create hybrid weapon icon with diagonal split.
    Top-right: breach weapon
    Bottom-left: ice weapon
    """
    breach = Image.open(breach_path).convert("RGBA")
    ice = Image.open(ice_path).convert("RGBA")
    
    width = breach.width
    height = breach.height
    result = Image.new("RGBA", (width, height), (0, 0, 0, 0))
    
    # Get content areas (non-transparent regions)
    breach_bbox = breach.getbbox()
    ice_bbox = ice.getbbox()
    
    if breach_bbox and ice_bbox:
        breach_left, breach_top, breach_right, breach_bottom = breach_bbox
        ice_left, ice_top, ice_right, ice_bottom = ice_bbox
        
        content_width = max(breach_right - breach_left, ice_right - ice_left)
        content_height = max(breach_bottom - breach_top, ice_bottom - ice_top)
        
        for y in range(height):
            for x in range(width):
                x_rel = x - min(breach_left, ice_left)
                
                # Diagonal split formula: top-right = breach, bottom-left = ice
                if y * content_width <= content_height * (content_width - x_rel):
                    pixel = breach.getpixel((x, y))
                else:
                    pixel = ice.getpixel((x, y))
                
                result.putpixel((x, y), pixel)
    
    result.save(output_path, "PNG")
    print(f"Created: {output_path}")

# Image pairs
images = [
    ("breach_one_bow.png", "ice_one_bow.png", "breach_ice_bow.png"),
    ("breach_two_bow.png", "ice_two_bow.png", "breach_ice_two_bow.png"),
    ("breach_three_bow.png", "ice_three_bow.png", "breach_ice_three_bow.png"),
    ("breach_ult_bow.png", "ice_ult_bow.png", "breach_ice_ult_bow.png")
]

for breach_img, ice_img, output_img in images:
    create_hybrid_image(breach_img, ice_img, output_img)

print("All images created successfully!")
```

1. MODIFIER STRUCTURE:
   - Primary weapon adds secondary modifier in OnCreated
   - Primary weapon removes secondary modifier in OnDestroy
   - Each weapon fires independently based on its own fire_rate

   - Breach weapons: HERO + BASIC only (no towers)

   - Primary weapon: dmg, fire_rate, range, speed, etc.
   - Secondary weapon: dmg_2, fire_rate_2, range_2, speed_2, etc.

4. PROJECTILE SYSTEM:
   - Use weapon_passive ability's FireProjectile method
   - Check if ability exists, add if not: if not self.parent:HasAbility("weapon_passive")
   - ExtraData carries ModifierName, ModifierLevel, ModifierDamage

5. BREACH MECHANICS:
   - Apply debuff modifier on projectile hit (OnRefresh)
   - Debuff uses StartIntervalThink with delay parameter
   - Damage split: pure_pct% pure, rest physical
   - Visual indicators: breach_ind.vpcf on apply, breach_boom.vpcf on damage

6. ICE MECHANICS:
   - Apply damage and slow modifier on projectile hit
   - Slow modifier uses DeclareFunctions for MOVESPEED_BONUS_PERCENTAGE
   - Return negative value for slow effect
   - Visual: ice_debuff.vpcf particle effect

   - Use get_errors to check Lua syntax
   - For large insertions, prefer replace_string_in_file over insert_edit_into_file

8. IMAGE COMPOSITION:
   - Diagonal split formula: y * content_width <= content_height * (content_width - x_rel)
   - Top-right: First weapon (breach)
   - Bottom-left: Second weapon (ice)
   - Use getbbox() to find content area for better split positioning

================================================================================
WEAPON MECHANICS REFERENCE
================================================================================

BREACH WEAPONS:
- Delayed damage (2.5 second delay typically)
- Split damage: 20% pure, 80% physical (default pure_pct = 20)
- Visual indicator on target while waiting
- Explosion effect when damage triggers
- Cannot target structures/towers

ICE WEAPONS:
- Instant damage on hit
- Applies movement speed slow debuff
- Slow percentage varies by level (slow_pct)
- Slow duration varies by level (slow_dur)
- Can target structures/towers
- Visual frost effect on slowed units

HYBRID BEHAVIOR:
- Both weapons fire independently at their own fire rates
- Player gets damage from both weapons simultaneously
- Each weapon maintains its own mechanics (delay vs instant, slow vs pure damage)
- Total DPS = (Breach DPS) + (Ice DPS)
